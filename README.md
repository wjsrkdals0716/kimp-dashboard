# 김프 & 펀딩비 모니터

업비트(KRW)와 바이낸스(USDT)의 BTC 가격을 환율로 맞춰 **김치 프리미엄**을 계산하고, 무기한선물 **펀딩비**를 나란히 보여주는 크립토 마켓 대시보드.

> 김프는 현물 **베이시스**다 — 같은 자산이 두 시장에서 다른 가격에 거래되는데, 원화 자본 이동 규제 때문에 차익거래로 닫히지 않는다. 펀딩비는 무기한선물의 베이시스 수렴 메커니즘. 이 프로젝트는 한국 크립토 시장의 이 구조적 지표들을 실시간으로 추적한다.

## 현재 상태

Day 1 (2026-07-30) — 거래소 API 수집 + 김프·펀딩비 계산 스크립트.

```

바이낸스 BTC/USDT :       63,986.04

------------------------------------
바이낸스 원화 환산 :     92,930,125

펀딩비 (8h)        :       +0.0089%  (연환산 +9.7%)
```
